--- Get-FixItListURLsv1 → Get-FixItListURLsv2  [2026-08-07 ~9:30–11:02 AM PT, ~1:01–1:44 PM PT] ---

- Permission validation: replaced Connect-ValidatedPnP with Test-ConnectedAccountPermissionSet
  (now also validates Graph scopes: Sites.Read.All, User.Read, Directory.Read.All) +
  Show-PermissionReauthPrompt for reauth/account-switch flow; added Update-PnPConnection /
  Reset-PnPAuthenticationConnection for mid-run refresh without full re-auth.
- Extension sets: replaced $SupportedExtensions/$LegacyExtensions with four explicit sets:
    $DocumentScannableExtensions : .docx .xlsx .pptx .pdf .doc .xls .ppt .txt .csv .rtf
    $OtherFileScannableExtensions: .htm .aspx
    $OpenXmlExtensions           : .docx .xlsx .pptx (ZIP-parsed separately)
    $AlwaysSkipExtensions        : .jpg .png .vsdx .one
- Output columns expanded: added Link Type, Document Title; split Last Modified into
  Created By / Last Modified By / Last Modified Date (see Schema E below).
- New helpers: Get-CentralParkCorrection, Get-LinkTypeLabel, Get-NormalizedExtension, Add-ExtensionCount.
- Added Set-ScriptWindowTitle — shows script name + Pacific start time in terminal title
  so long-running jobs are identifiable without opening the session.
- CSVs always written; placeholder row when findings = 0.
- File naming: now prefixes site title slug + script slug + report type + timestamp.


--- Get-FixItListDocsOnly → Get-FixItListOverviewOnly  [2026-08-07 ~9:30–11:02 AM PT, ~1:01–1:44 PM PT] ---

- Renamed: "DocsOnly" → "OverviewOnly" so output CSVs are distinguishable from
  URL-detail reports at a glance in the file listing.
- Permission validation: same swap as URLsv2 — Connect-ValidatedPnP replaced with
  Test-ConnectedAccountPermissionSet + Show-PermissionReauthPrompt.
- Added Set-ScriptWindowTitle (same as URLsv2) — script name + Pacific start time in
  terminal title for easy identification during long runs.
- Extension arrays ($SupportedExtensions, $LegacyExtensions) unchanged — expansion
  applies to URLsv2 only.
